# Code of Conduct

## Our Pledge

We want Vocex Run to be an open and welcoming project for everyone.

## Expected Behavior

- Be respectful
- Give constructive feedback
- Avoid harassment or toxic behavior
- Help improve the project positively

## Unacceptable Behavior

- Harassment or hate speech
- Personal attacks
- Spam or malicious contributions

## Enforcement

Project maintainers may remove or reject contributions that violate this code of conduct.

---

By participating in this project, you agree to follow these guidelines.
