# Contributing to Vocex Run

Thanks for your interest in contributing to Vocex Run.

## Reporting Bugs

If you find a bug, please open an issue and include:

- Device name
- Android version
- Steps to reproduce
- Screenshots or recordings if possible

## Suggesting Features

Feature requests are welcome. Please describe:

- What the feature does
- Why it would improve gameplay
- Possible implementation ideas

## Code Contributions

1. Fork the repository
2. Create a feature branch
3. Commit your changes clearly
4. Open a pull request

## Guidelines

- Keep code readable and documented
- Test gameplay changes before submitting
- Avoid unnecessary dependencies
